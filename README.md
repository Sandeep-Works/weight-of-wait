# Moodful Loaders — The Weight of Waiting

Twenty-four hours. Twenty-four moods. Twenty-four ways loading can feel human.

A beautiful, interactive web experience showcasing 24 unique loading animations, each representing a different emotional state during waiting.

## Features

- 24 unique mood-based loading animations
- Smooth scroll-based navigation
- Responsive design
- Accessibility features
- Reduced motion support

## Deployment

This project is deployed on Vercel and can be accessed via the live link.

## Technologies

- HTML5
- CSS3 (with CSS Animations)
- Vanilla JavaScript

## Local Development

Simply open `index.html` in a browser or use a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`
